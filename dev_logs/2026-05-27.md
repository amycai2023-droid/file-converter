## 当前架构
```
浏览器 ──本地转换──→ TXT/MD/HTML/JSON/CSV/TSV/XML/YAML/TOML/INI
    │
    └──上传到后端──→ DOCX/PDF/XLSX/RTF/DOC/TEX/Parquet/Feather/SQL
         (FastAPI)      │
                   Pandoc + PyMuPDF + pdfplumber + pandas + pyarrow
```
