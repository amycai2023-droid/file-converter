# UI设计规范

## 设计原则
- **简洁至上**：每个页面只做一件事
- **即时反馈**：每个操作都有明确的视觉反馈
- **移动优先**：确保手机浏览器体验同样流畅
- **无障碍**：足够大的点击区域，清晰的文字对比度

## 色彩方案

| 用途 | 颜色 | 色值 |
|------|------|------|
| 主色调 | 蓝色 | #2563EB (blue-600) |
| 主色调悬停 | 深蓝 | #1D4ED8 (blue-700) |
| 背景色 | 浅灰 | #F9FAFB (gray-50) |
| 卡片背景 | 白色 | #FFFFFF |
| 文字主色 | 深灰 | #111827 (gray-900) |
| 文字副色 | 中灰 | #6B7280 (gray-500) |
| 边框色 | 浅灰 | #D1D5DB (gray-300) |
| 成功色 | 绿色 | #16A34A (green-600) |
| 错误色 | 红色 | #DC2626 (red-600) |

## 字体
- 系统默认字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- 标题：font-semibold
- 正文：font-normal
- 代码/文件名：font-mono

## 布局

### 桌面端（≥768px）
- 上传区域居中，最大宽度480px
- 格式选择弹窗居中，最大宽度400px

### 移动端（<768px）
- 上传区域全宽，左右各留16px边距
- 格式选择弹窗从底部弹出（Bottom Sheet样式）

## 组件规格

### UploadZone（上传区域）
- 外观：虚线矩形边框，2px dashed，圆角12px
- 尺寸：高度200px，宽度100%
- 状态：
  - 默认：灰色虚线 + "拖拽文件到此处或点击选择"
  - 拖拽悬停：蓝色虚线 + 蓝色浅底 + "释放以上传"
  - 已选择：显示文件名、大小、格式标签
- 图标：上传图标（SVG），居中放置
- 支持格式提示：小字灰色显示在下方

### FormatSelector（格式选择弹窗）
- 外观：白色卡片，圆角16px，阴影
- 标题："选择目标格式"
- 搜索框：顶部，带搜索图标
- 格式列表：网格布局，每个格式一个圆角按钮
  - 默认：白底灰边框
  - 悬停：蓝底白字

### ConversionProgress（转换进度）
- 动画进度条（蓝色）
- 状态文字："正在转换..."
- 完成："转换完成！"

### DownloadButton（下载按钮）
- 蓝色实心按钮，圆角8px
- 文字："下载 [格式名] 文件"
- 自动触发浏览器下载
